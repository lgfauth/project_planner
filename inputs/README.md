# inputs/

Material de referência que você traz para embasar o planejamento.

**Somente leitura para a IA.** Nada aqui é editado ou apagado durante o processo.

## O que colocar aqui

- Pesquisas, entrevistas e transcrições
- Documentos de requisitos existentes, atas, e-mails relevantes
- Prints, exports de planilhas, dados de uso
- Documentação de sistemas legados ou de APIs que serão integradas
- Referências de concorrentes e benchmarks

## Convenções

- Um assunto por arquivo; nome descritivo em kebab-case: `pesquisa-usuarios-2026-08.md`
- Prefixe com o slug do projeto quando o input for específico: `portal-cliente_entrevista-vendas.md`
- Formatos preferidos: `.md`, `.txt`, `.csv`, `.pdf`. Imagens em `.png`/`.jpg`.
- Se o documento for confidencial, anonimize antes de trazer.

Tudo que sair de um input é citado como `[FONTE: inputs/<arquivo>]` nos documentos gerados.
